# @moriajs/cli

The command-line interface for MoriaJS.

## Commands

- `moria dev` — Start development server with HMR
- `moria build` — Build for production
- `moria start` — Start production server
- `moria generate <type> <name>` — Generate route, component, or model

## Installation

```bash
npm install -g @moriajs/cli
```

## Version

The CLI version is read from its own `package.json` at runtime (v0.4.40+), ensuring it always matches the published package version.
